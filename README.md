# DIC-Visualisierung

Lokale Visualisierung und Simulation der DIC-Firmware.

## Funktionen

- Darstellung des 20×4-LCD-Displays und der LEDs
- Simulation von CAN-Nachrichten und Fahrzeugdaten
- Anpassbare Sensorwerte und Fehlerzustände
- Automatische Aktualisierung bei Firmware-Änderungen
- Unterstützung lokaler Git-Branches

## Installation und Start

**macOS:** `Einrichtungsscripts/Start_macOS.command`

**Windows:** `Einrichtungsscripts/Einrichtung_Windows.bat` (einmalig), danach `Einrichtungsscrips/Start_Windows.bat`

## Verwendung

1. Programm starten.
2. Lokales DIC-Firmware-Repository auswählen.
3. Firmware-Branch auswählen.
4. Fahrzeugdaten unter „Beispielwerte“ anpassen.
